# BioTrial

Projeto final da disciplina de Programação de Aplicativos - SENAI/SC.

Aplicativo PWA em React para registrar testes científicos (reagentes e medicamentos), com o resultado de cada teste: Sucesso, Falha ou Em andamento.

## Funcionalidades

- Cadastro de testes (reagente, responsável, data, dosagem, resultado e observações)
- Listagem dos testes
- Pesquisa pelo nome do reagente
- Edição e exclusão de testes
- Resumo na página inicial (sucessos, total e falhas)
- Dados salvos no localStorage
- Configurado como PWA (manifest e service worker)
